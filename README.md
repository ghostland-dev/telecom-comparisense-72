# Telecom ComparisSense

Compare mobile and internet plans across providers.

## Features

- Plan comparison
- Provider pages and guides
- Clerk authentication

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Clerk

## Getting Started

```bash
git clone https://github.com/ghostland-dev/telecom-comparisense-v2.git
cd telecom-comparisense-v2
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview

## Deploy

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fghostland-dev%2Ftelecom-comparisense-v2)

Click the button to deploy your own copy on Vercel in one step.

Set these environment variables in the Vercel project settings (see `.env.example`):

- `VITE_CLERK_PUBLISHABLE_KEY`
