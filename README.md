# Telecom ComparisSense

Compare mobile and internet plans across providers.

## Features

- Plan comparison
- Provider pages and guides
- Clerk authentication

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Clerk

## Getting Started

```bash
git clone https://github.com/ghostland-dev/telecom-comparisense-v2.git
cd telecom-comparisense-v2
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
